# Escola Trilha Digital (fictícia)

Site de uma escola **fictícia**, criado para demonstrar o AFL (Agents for Life). Não é uma empresa real e nada aqui está à venda.

O botão "Tire suas dúvidas" abre um app público do AFL em que um agente responde sobre cursos, preços e turmas
e registra a lista de espera da próxima turma.

Publicado com GitHub Pages a partir de `index.html`.
